# 陈佳茜个人 Profile 网站

双击本文件夹中的 `index.html` 可在本机打开。发布版使用同一套页面与视频文件。

页面按 HR 的阅读顺序组织：个人定位 → 四张平台数据原图 → 业务诊断与组会图表 → 在线工具实景 → 六条成片 → 作品集原图 → 商业与英文研究作品 → 跨场景经历 → 联系入口。首页使用本人照片。六条视频已放入 `assets/videos/`，离线可播放；五个工具链接需要联网。作品集、研究作品和平台数据截图可以点击放大。

当前明确保留的待补信息：

1. 四张截图显示 HEEL 军团作品 78 万播放、RIVER 抽烟舞作品 17.6 万播放。网站仅使用截图时数值，不将舞蹈作品数据归到网易开营成片。公开发布页及原视频待补充。
2. 根据岗位准备的最终简历文件或公开下载链接。现在网站只说明有岗位定向版本，未把旧草稿当成正式简历发布。
3. 若希望逐项展示个人独立贡献，可补充视频发布页、数据统计日期和工具的个人工作说明。

网站不包含原始订单表、家长对话、内部会议记录全文或手机号。业务案例使用聚合数字及去除个人名单的原始图表，并说明口径与验证边界。研究区只展示选定页面，不公开带有学号的论文封面。

联系区直接显示两个邮箱，均可通过邮件链接联系。复制按钮在浏览器允许剪贴板访问时直接复制；若浏览器拦截，会选中邮箱地址供手动复制。
